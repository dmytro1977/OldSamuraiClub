- [EMS + RAM DISK driver](EMS_driver/README.md), RAM disk survives hard reset
- [utilities](utilities/README.md):\

- [test_87](test_87/README.md): reengineered version of 8087 coprocessor tests\

- [mdatest1](mdatest/README.md): test display memory for dual mono/color display configuration
- [gal16v8](gal16v8/README.md): implementation of 7-bit counter for GAL16V8
- [xtide](idext/README.md): simple program to access IDE drive via IDE-XT ports
